
# 🏆Jogo de Heróis com Classes e Objetos - Desafio-Dio
📌 Objetivo:
Criar uma classe genérica que represente um Herói de uma aventura e que possua as seguintes Propriedades:

- nome
- idade
- tipo (guerreiro, mago, monge, ninja)

### Oque deve ser utilzado:

✅ Variáveis

✅ Operadores

✅ Laços de repetição

✅ Estruturas de decisão

✅ Funções

✅ Classes e Objetos


### Método: atacar() 

Que deve atender os seguintes requisitos:

O {tipo} {nome} atacou usando {ataque}

Ataques por tipo:
| Tipo      |  Nome         | Ataque          |
| --------- |---------------| --------------- |
| mago      |  William      |  magia          |
| guerreiro |  Godae        |  espada         |
| monge     |  Shylion      |  artes marciais |
| ninja     |  Brucee       |  shuriken       |
